## PRE-CHANGE FACTS

- Endpoint/problem: `PlanProgressView.render()` u
  `src/flowos/gui/views/plan_progress.py` je svaki neprazan `data` označavao
  kao `Aktivni plan: {plan_title}`, bez obzira na `plan_status`.
- Code path potvrđen read-only:
  `OverviewController._on_plan_progress` (src/flowos/gui/controllers/overview.py:66)
  emituje `plan_status` iz `plan.get("status", "")` →
  `CompositionRoot._on_plan_progress` (src/flowos/gui/composition_root.py:292)
  prosljeđuje taj dict u `self._plan_page_view.render(data)`.
- `render()` već prima dovoljno podataka: `data["plan_status"]` je prisutan.
  Nije potrebna izmjena controllera ni backend-a.
- Backend za odsustvo plana vraća `plan: None`; controller mapira u
  `plan_status: ""` i `plan_title: ""`.

- src/flowos/gui/views/plan_progress.py (samo `render()` oznaka)
